Los archivos que se encuentran en el repositorio son:

- funcionAzure: la función de Azure que se usa para la evaluación.
- practica1_soluciones: son los ejercicios resueltos como ejemplo para poder simular ejercicios de prácticas en entorno educativo.
- pipeline_v1: pipeline Script de Jenkins que simula x despliegues concurrentes en Jenkins de la evaluación de los repositorios de Github.
- pipeline_v2: pipeline Script para ejecutar x despliegues con funciones de Azure.
- dispatcher_v1: es el pipeline Script de Jenkins que realiza un despliegue de la versión v1, job pipeline_v1.
- lab_env.radl: es la plantilla con la que se ha desplegado la máquina Jenkins.
